# CMU 11-768 AI Agents 中文精读 · 课件

CMU 2026 秋季新课 [11-768 AI Agents](https://cmu-agents.com)（Graham Neubig、Daniel Fried）的非官方中文精读。整门课 23 讲，每一讲都有一支中文讲解视频和一份配套课件；CMU 每周上两讲，这里跟着更新。

课件是写给学习者的详细教程：每一讲有学习目标、图文讲解、源码解读、小结、术语表、思考题（附参考答案）、动手练习和延伸阅读，可以配合视频学，也可以单独读。每一讲的目录里有：

- `README.md`：这一讲的课件正文，点进目录就能直接读。
- `images/`：正文配图，也就是视频里每块内容讲完时的完整画面。
- `lNN-幻灯片.pdf`：所有配图按顺序合成的一份 PDF，方便下载、打印或边看视频边翻。
